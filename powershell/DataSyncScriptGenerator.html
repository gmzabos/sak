📋 So verwendest du das Skript:

  1. Speichern: Kopiere den Code und speichere ihn in eine Datei namens sync-daten.ps1
  2. Ordner: Speichere die Datei z.B. auf dem Desktop oder in C:\Scripts
  3. Ausführung: Klicke mit der rechten Maustaste auf die .ps1 Datei
  4. Kontext-Menü: Wähle "Mit PowerShell ausführen" oder doppelklick mit Shift
  5. Genehmigung: Bestätige eventuell eine Sicherheitsmeldung
  6. Fertig: Das Skript startet und synchronisiert deine Daten 🎉
⚡ Tipp: Falls Doppelklick nicht funktioniert, öffne PowerShell als Administrator und führe aus: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
